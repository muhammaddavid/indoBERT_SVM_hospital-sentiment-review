# indoBERT_SVM_hospital-sentiment-review
Merupakan proyek tugas akhir atau skripsi yang membahas komparasi model IndoBERT dan Support Vector Machine (SVM) dalam melakukan analisis sentimen pada ulasan rumah sakit berbahasa Indonesia. Proyek ini bertujuan untuk mengevaluasi dan membandingkan performa kedua model dalam mengklasifikasikan ulasan pasien ke dalam sentimen positif dan negatif.
# Dataset
Dataset yang digunakan dalam penelitian ini berasal dari dataset “Indonesian Hospital Review Dataset XLSX [25K]” oleh Andreas Kentjana yang dipublikasikan melalui Mendeley Data pada tahun 2025. Dataset ini berisi kumpulan ulasan rumah sakit berbahasa Indonesia yang digunakan untuk kebutuhan analisis sentimen pada penelitian ini.

Sitasi dataset:

Kentjana, Andreas (2025), “Indonesian Hospital Review Dataset XLSX [25K]”, Mendeley Data, V1, doi: 10.17632/pms729gs8n.
